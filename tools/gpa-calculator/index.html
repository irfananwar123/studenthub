GPA Calculator

This GPA calculator lets you define grade points yourself and weight each subject by its credits. Use it to explore how different grades would affect your semester or overall average before results are published.

How the calculation works

GPA = Σ(grade points × subject credits) ÷ Σ(credits). Subjects with more credits influence the result more heavily.

Worked example

Example: A (4.0) in a 3-credit course and B (3.0) in a 4-credit course gives (12 + 12) ÷ 7 = 3.43.

How to use this page

  1. Edit the grade-point lines if your school uses a different scale.
  2. Fill in subjects, credits and grades.
  3. Select Calculate GPA for the weighted average and a full breakdown.

Frequently asked questions

What is the difference between GPA and CGPA?

GPA commonly describes one term; CGPA usually covers all completed terms. This tool calculates whichever set of subjects you enter.

Can I enter numeric points instead of a letter grade?

Add a line such as 95,4.0 in the configuration box and type 95 as the grade for a subject.

Are plus and minus grades supported?

Yes, any label you define in the configuration box is accepted, including A− and B+.
