Random Question Picker

Use a random question to break up a revision session or choose a topic for the whole class. Add your own list, pick one at once and avoid immediate repeats when there is more than one question.

How the calculation works

A random index is generated in the range 0 to number of questions − 1. If “avoid repeats” is enabled and more than one question exists, a new index is drawn until it differs from the previous one.

Worked example

Example: with five questions and repeat avoidance on, choosing again after question 3 will choose from the other four questions. With only one question, it is selected every time.

How to use this page

  1. Add questions one at a time.
  2. Select Pick a question for a random prompt.
  3. Remove questions you no longer need from the list.
Everything on this page runs in your browser. Your entries are not uploaded or stored on a server.

Frequently asked questions

How random is the picker?

It uses the browser’s crypto random source when available and falls back to Math.random; it is suitable for practice, not for security.

Are questions stored?

Yes, in your browser’s local database, so they survive a refresh.

Can I reset the list?

Yes, each question has its own Remove button.
