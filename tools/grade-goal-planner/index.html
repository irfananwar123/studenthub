Grade Goal Planner

Set a target percentage, enter the marks you already have and list what is still to come. The planner calculates the marks you need overall, the percentage required across remaining work and a fair per-assessment target. It is honest when a goal is already secured or no longer reachable.

How the calculation works

Grand total is marks available so far + Σ remaining maximum marks. Required total is target percentage ÷ 100 × grand total. Needed from remaining work is required total − marks earned so far. If that number is positive and no greater than the remaining marks available, the required percentage is needed ÷ remaining available × 100, and each assessment gets needed ÷ remaining available × that assessment’s maximum.

Worked example

Example: You have 60 out of 80 so far and one assessment worth 20 marks remains. To finish at 80% overall you need 80 of 100 marks in total, so you must score 80 − 60 = 20 from the last assessment — 100% of it. If you already had 90 of 80 (including bonus marks), the target would be secured; if only 5 marks remained, the target would be impossible.

How to use this page

  1. Enter your target percentage and the marks you have earned and could have earned so far.
  2. Add each remaining assessment with the maximum marks it offers.
  3. Select Calculate required marks.
  4. Read the overall target, the percentage needed from remaining work and each assessment target.
  5. Save the plan locally to restore it next time, or reset to start again.
Everything on this page runs in your browser. Your entries are not uploaded or stored on a server.

Frequently asked questions

What does “impossible” mean?

Even full marks on all remaining assessments would not reach the target. The planner shows the shortfall so you can revise the goal honestly.

What if I have already passed the target?

The result says the target is already secured and shows your current percentage above the goal.

Can I use weighted modules?

Enter each module’s maximum marks as an assessment. Maximum marks act as the weight in the calculation.

Is my plan uploaded?

No. The last plan is kept in LocalStorage on this device and never transmitted.
