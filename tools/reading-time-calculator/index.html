Reading Time Calculator

Estimate how long an article, chapter or essay will take to read. Enter a word count or paste text, set a reading speed, and see the result in minutes and seconds.

How the calculation works

minutes = word count ÷ words per minute. Common adult reading speeds are around 200–250 words per minute; technical material is often slower.

Worked example

Example: 1,200 words at 200 words per minute takes 6 minutes. At 250 wpm it takes 4.8 minutes, about 4 minutes 48 seconds.

How to use this page

  1. Enter a word count or paste text.
  2. Set a realistic reading speed.
  3. Select Estimate reading time.

Frequently asked questions

What is a typical reading speed?

Around 200–250 words per minute for general text; use a lower value for dense or technical material.

Does this measure comprehension time?

No. It only estimates time to read the words, not time to think or take notes.

Can I use it for a presentation?

Yes, set your own speed to plan roughly how long a script will take to deliver.
