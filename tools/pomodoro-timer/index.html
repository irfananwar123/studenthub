Pomodoro Timer

Work in focused blocks with planned breaks. Set your own work and break lengths, start or pause with a click or the space bar, and keep a count of completed sessions. The timer uses real elapsed time so background tabs do not drift.

How the calculation works

The timer stores an end timestamp when started. Remaining time is end time − current time, recalculated on each tick. If the browser throttles a background tab, the next tick corrects the display instead of losing time.

Worked example

Example: with 25-minute work and 5-minute breaks, four completed work sessions trigger a longer break if you set the long-break interval to 4. Sessions are counted only when a work block reaches zero.

How to use this page

  1. Set work and break lengths.
  2. Select Start, then Pause if you need to stop.
  3. Turn on sound if you want an audible cue; the browser may ask for permission to play audio.

Frequently asked questions

Does the timer keep running in another tab?

Yes. It checks the actual clock rather than counting interval ticks, so throttled tabs do not slow it down.

Will it make noise without permission?

No. Sound is off until you enable it, and audio playback may still be blocked by your browser until you interact with the page.

Is the Pomodoro method right for everyone?

It is a popular focus technique, not a guarantee of productivity. Adjust the durations to suit your attention span.
