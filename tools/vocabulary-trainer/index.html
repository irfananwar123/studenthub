Vocabulary Trainer

Build your own vocabulary list for any language or subject. Add definitions, search your collection and switch to practice mode to test yourself without seeing the answer first.

How the calculation works

Practice presents one word at a time in random order. Revealing the definition is a deliberate action, so the recall attempt happens before the answer is shown.

Worked example

Example: add “mitochondria → organelle that releases energy from food” to a Biology collection. In practice mode, try to say the definition before selecting Reveal definition.

How to use this page

  1. Add a word, its definition and a collection name.
  2. Filter or search your collection.
  3. Switch to practice mode and reveal definitions only after trying to recall them.
Everything on this page runs in your browser. Your entries are not uploaded or stored on a server.

Frequently asked questions

Can I use this for more than one language?

Yes. Give each language a different collection name and filter by it.

Is there pronunciation audio?

No; the tool stores only the text you enter.

Can I import a word list?

Individual tools do not import yet, but you can restore a full StudentHub backup from the Workspace page.
